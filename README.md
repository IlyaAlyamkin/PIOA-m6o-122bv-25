## Функциональность

- **Добавление записи** (`create_record`): поля id, имя, фамилия, возраст, пол; обрезка пробелов в строках; проверка уникальности id и неотрицательного возраста.
- **Просмотр всех записей** и **поиск по фильтрам** (`select_record`): любое сочетание полей; пустые фильтры — вся таблица.
- **Обновление записи** (`update_record`): по id, частичное обновление полей (непереданные поля не меняются).
- **Удаление записи** (`delete_record`): по id.
- **Ошибки** оформлены классами в `errors.py`: `InvalidAgeError`, `DuplicateIDError`, `RecordNotFoundError` (наследуют `StudentTableError`).
- **TUI** (`tui.py`): класс **`TUI`** с таблицей `StudentTable` на сеанс; пункты меню 1–5 и выход `0`. Функция **`run()`** создаёт `TUI()` и вызывает `run()`.

## Запуск приложения

Из корня репозитория (рядом с папкой `src`):

```bash
python -m src.db
```

## Тесты и покрытие

Установка зависимостей для прогона с покрытием:

```bash
pip install pytest pytest-cov
```

Запуск тестов с **контролем покрытия ≥ 80%** (порог задан в `pyproject.toml`):

```bash
python -m pytest
```

Подробный отчёт по строкам:

```bash
python -m pytest --cov=src --cov-report=term-missing
```

Только `unittest` (без проверки coverage):

```bash
python -m unittest discover -s tests -p "test_*.py" -v
```

## Требования

- Python **3.12+** (используется синтаксис `type StudentRecord = ...`).

## Стандарты кода

- Стиль и оформление: **PEP 8** (две пустые строки между функциями верхнего уровня, осмысленные имена, узкие исключения в TUI — `StudentTableError`).
- Резервные ветки `import` для запуска из подкаталога помечены **`# pragma: no cover`**, так как в штатном сценарии используется пакет `src.db`.
